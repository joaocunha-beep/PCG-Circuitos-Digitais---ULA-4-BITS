Este projeto implementa uma ULA (Unidade Lógica e Aritmética) de 4 bits, capaz de 
realizar operações aritméticas e lógicas: adição, subtração, multiplicação, divisão, AND, OR, 
XOR, NOT e verificação de igualdade. Um sinal de controle seleciona a operação executada, 
e a ULA fornece o resultado correspondente.
